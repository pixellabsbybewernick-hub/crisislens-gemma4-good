# Final Kaggle submission checklist

## Must-have before submitting

- [ ] Kaggle account joined to the competition.
- [ ] Identity verification complete if prize eligibility requires it.
- [ ] Public GitHub repository created.
- [ ] Repo includes code, README, requirements, screenshots/assets, and license.
- [ ] Streamlit app runs locally from a clean checkout.
- [ ] `pytest -q` passes.
- [ ] App tested with at least one sample scenario.
- [ ] If possible, run local Gemma 4 through Ollama and capture it in the video.
- [ ] Public 3-minute YouTube video uploaded.
- [ ] Kaggle writeup pasted from `submission/KAGGLE_SUBMISSION_FINAL.md` or `WRITEUP_KAGGLE.md`.
- [ ] Live demo link, Kaggle Notebook, or reproducible local-demo instructions included.
- [ ] Cover image / media gallery assets uploaded.
- [ ] Do not claim that fallback output is Gemma output.

## Best track positioning

- [ ] Primary: Global Resilience.
- [ ] Secondary: Safety & Trust.
- [ ] Special technology: Ollama / Local Ops, only if local Gemma via Ollama is shown.
