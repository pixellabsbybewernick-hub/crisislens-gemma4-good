# Judging strategy for CrisisLens

## Primary prize angle

CrisisLens should be positioned as a **Global Resilience** project with a strong **Safety & Trust** component. If the final demo uses local Gemma 4 through Ollama, also position it for the **Ollama/local-first** track.

## Why it can score well

### Impact & Vision

The problem is concrete: disaster coordinators receive chaotic images and messages under time pressure. CrisisLens converts them into structured, actionable reports.

### Video Pitch & Storytelling

The before/after demo is visually obvious:

- before: one image + messy short note
- after: urgency, risks, uncertainty, missing questions, routing, SMS summary

### Technical Depth & Execution

The project goes beyond a chatbot:

- multimodal input
- strict JSON schema
- multilingual output
- deterministic routing tool
- human-in-the-loop safety
- batch triage view
- downloadable reports
- local-first deployment path

## Suggested 30-second pitch

CrisisLens is a local-first crisis-reporting assistant built with Gemma 4. In disasters, field teams often send only photos and short messages. CrisisLens turns that messy evidence into a structured report with urgency, risks, uncertainty, missing questions, routing recommendations, and an SMS-ready summary. It keeps humans in control and works toward low-connectivity, privacy-sensitive deployment.
